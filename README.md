# Cal.Lightman photography

A personal archive of 42 photographs by Qin Yingjie / Cal.Lightman.

Mountains, a daylight gallery, a three-photo collage and a looping curved film wall form one continuous viewing experience. Includes full-image viewing, responsive layouts and reduced-motion support.

This repository contains the public static site only. Open `index.html` through a web server; no build is required. GitHub Pages publishes the `main` branch root.

Photography copyright belongs to the photographer. Third-party font, Three.js and material licenses are included under `assets/fonts/` and `assets/licenses/`.
